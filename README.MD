Qual é a diferença entre Working Directory, Staging Area e Repository?
Working Directory são os arquivos em alteração; Staging Area são os arquivos preparados para o commit; Repository é onde ficam os commits e o histórico.

Qual é a diferença entre git commit e git push?
git commit salva as alterações localmente. git push envia os commits para o GitHub

É possível realizar vários commits antes de executar um git push? Explique.
Sim. Podemos fazer vários commits localmente e depois enviar todos com um único git push.

Por que é interessante realizar commits pequenos e descritivos?
Facilita entender o histórico e identificar alterações específicas.

O que acontece com os commits locais quando ainda não executamos o git push?
Eles continuam salvos localmente, mas ainda não aparecem no GitHub.

Como verificar, pelo GitHub, se os commits foram enviados corretamente?
Acessando o repositório no GitHub e verificando o histórico de commits.
